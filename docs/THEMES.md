# 主题与颜色

从首页的「外观 → 主题与颜色」进入，所有设置即时生效并保存在本机。

- 关闭随机主题色时，使用固定颜色。可选 10 个预设，也可输入 `#RRGGBB` 自定义颜色。
- 开启随机主题色后，可选「每天换色」或「每次启动」。关闭随机后恢复保留的固定颜色。
- 每天换色按设备本地日期判断，同一天重新打开应用保持原色；前台跨过午夜、日期或时区变动时重新检查。
- 每次启动在重新启动应用后的首次打开界面时换色。页面切换、旋转、临时离开后返回不重复换色；后台服务与自动链接桥接不消耗用户启动次数。
- 日夜模式可跟随系统，也可固定为浅色或深色。日夜共用同一个主题色系，仅改变各层明度；切换日夜不会重新随机选色。

页面背景、中卡片、小卡片、输入框、选中项、开关、弹窗、系统栏和经典应用选择卡共用颜色定义。正文和摘要使用经过对比度校验的颜色；错误提示保留红色语义。黑、白、灰等中性色在日夜中保持灰阶。

设置页的并排预览以同一个主题色展示白天和夜间效果，包括中、小两种卡片。随机开启时编辑固定颜色只修改保留值，关闭随机后再应用该固定色。

## 维护与验证

`ThemePolicy` 决定换色时机，`ThemePreferencesStore` 持久化设置，`ThemePalette` 从同一主题色生成 Miuix 和 Material3 颜色。`IceBridgeTheme` 处理系统外观、日期变化与前台午夜更新，`ThemeCard` 区分中小卡片。

所有 Compose 页面使用 `setIceBridgeContent` 安装内容：更新 Decor 的 Lifecycle、ViewModelStore、SavedStateRegistry owners，并使用新的满屏 ComposeView。旧 AppCompat 与新版 Activity Compose 混用时，直接复用旧 ComposeView 会在 Activity 重建后留下空白界面。外观切换通过颜色状态更新，不主动重建整个应用的界面。

策略、颜色对比度与启动次数由 JVM 测试覆盖；设备测试 `ThemeRenderingTest` 覆盖日夜切换、页面重建后的内容可见性及启动随机色保持。Android 16 模拟器上的主题验证不代表实际 ROM、LSPosed 或解冻链路验证。
